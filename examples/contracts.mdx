One page per agreement (`contracts/<counterparty>`): an agent-written plain-language summary.

**Metadata**: `renewal-date`, `auto-renews`, `risk-score`, `counterparty`, `governing-law`, `clauses-flagged`.

The general counsel's monthly sweep:

```bash
coco query --space contracts \
  --filter auto-renews=true \
  --filter 'renewal-date<"2026-12-10"' \
  --order-by risk-score --desc
```

Per-key metadata history answers the follow-up question: _"who lowered this risk score, and when."_
