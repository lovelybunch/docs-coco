One page per account (`sales/customer-<name>`).

**Metadata**: `confidence-score`, `sources`, `arr-band`, `renewal-date`, `verified`.

A **HubSpot connector** keeps CRM facts flowing in. The reps' pre-renewal view, as a query anyone can run:

```bash
coco query --space sales \
  --filter 'renewal-date<"2026-10-01"' \
  --filter 'confidence-score<0.6' \
  --order-by renewal-date
```

Every number on the page is traceable to its source list.
