title: "Support and SRE runbooks"
description: "Runbooks that know their own freshness"
icon: "book-open"
---

One page per runbook (`ops/runbook-<service>`).

**Metadata**: `last-tested`, `owner`, `criticality`, `linked-incidents` (appended by the agent via a **Linear/Sentry** connector).

The quarterly audit view:

```bash
coco query --space ops \
  --filter 'criticality in high,critical' \
  --filter 'last-tested<"2026-06-11"' \
  --order-by last-tested
```

A `page.updated` webhook pings the on-call channel when a runbook changes. The metadata history answers _"who last attested this runbook."_
