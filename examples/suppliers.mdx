description: "Concentration risk and portable audit evidence"
icon: "industry"

One page per vendor (`supply/vendor-<name>`).

**Metadata**: `audit-score`, `next-audit`, `certifications` (array), `single-source`, `open-capas`.

**Concentration risk**:

```bash
coco query --space supply \
  --filter single-source=true --filter 'audit-score<0.8' \
  --order-by audit-score
```

**Line-transfer qualification**:

```bash
coco query --space supply --filter 'certifications~ISO-13485'
```

Export the space as the auditor's evidence bundle.
