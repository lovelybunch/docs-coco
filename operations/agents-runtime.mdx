description: "Native mode and the Eve runtime container"

---

Space agents need somewhere to execute. Native mode runs them inside your own deployment, in a runtime container alongside the API, rather than delegating to an external client.

Enable it on the API:

```bash
COCO_NATIVE_AGENTS_MODE=native
```

Then run the agents runtime container alongside the API. On multi-tenant deployments, per-org entitlements control which organizations can use it.

See [Agents](/concepts/agents) for how tasks, schedules, and run records are structured, and [Connectors](/concepts/connectors) for how a running agent reaches external systems.
