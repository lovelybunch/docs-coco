Coconut ships with three ready-made deployment paths. The enterprise artifact is `api + postgres`; the Next.js app is optional.

<CardGroup cols={3}>
  <Card title="Docker Compose" icon="docker">
    `./scripts/compose-local.sh` runs Postgres, the API, and the app on your laptop.
  </Card>

  <Card title="Kubernetes" icon="dharmachakra">
    `./scripts/k8s-local.sh` brings up kind with the Helm chart for a cluster smoke test.
  </Card>

  <Card title="AWS" icon="aws">
    Terraform and reference architectures, published with the deployment guide.
  </Card>
</CardGroup>

## Migrations

```bash
pnpm db:migrate
```

Migrations are idempotent and ordered, so re-running is safe.

## Secrets at rest

Webhook secrets, connector credentials, and model keys are encrypted with `COCO_SETTINGS_ENCRYPTION_KEY`, which is 32 bytes, base64-encoded:

```bash
openssl rand -base64 32
```

<Warning>
  Without `COCO_SETTINGS_ENCRYPTION_KEY`, creating or rotating a webhook signing secret returns `503`. Same posture applies to connector credentials.
</Warning>
