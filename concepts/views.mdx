title: "Views"
description: "The human window onto the metadata query engine"
icon: "table"
---

Views (`/views` in the app) is the human window onto the metadata query engine agents already use. Build filters (key / operator / value), scope to a space, order by any key, and get a table of matching pages with their metadata values as columns.

The whole view state lives in the URL, so a tuned view is shareable as a link and bookmarkable as a team dashboard. One example: _"diligence-stage deals with conviction at or above 0.7, worst-reviewed first."_
